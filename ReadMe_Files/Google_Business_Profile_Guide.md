## How to Edit Details Later

**Everything is editable anytime:**

1. Go to https://business.google.com
2. Login with your Gmail
3. Click on your business
4. Click **"Edit profile"**
5. Change any field — phone, address, hours, description, photos
6. Click **Save**
7. Changes reflect on Google within **1-3 days** (sometimes within hours)

### Common edits:

| Want to change | Where |
|---------------|-------|
| Phone number | Edit profile → Contact → Phone |
| Business hours | Edit profile → Hours |
| Address | Edit profile → Location |
| Description | Edit profile → About → Description |
| Add photos | Photos → Add photos |
| Remove photos | Photos → click photo → Delete |
| Add a service | Edit profile → Services → Add |
| Website URL | Edit profile → Contact → Website |

## Getting Google Reviews

### How to ask customers for Google reviews:

**Share your Google review link:**
1. Go to https://business.google.com
2. Click **"Ask for reviews"** or **"Get more reviews"**
3. Copy the review link Google provides
4. Send to customers via WhatsApp

**Sample message:**
```
Hi [Name]! Thank you for traveling with Ganesh Holidays! 🙏

If you enjoyed the trip, please leave us a review on Google:
[paste your Google review link here]

Your review helps others find us! ⭐
```

**Tip:** Ask for both Google review AND website review:
- Google review → helps your search ranking
- Website review → shows on ganeshholidays.in

## Google Reviews vs Website Reviews

| | Google Reviews | Website Reviews |
|---|---------------|----------------|
| Where it shows | Google Search, Google Maps | ganeshholidays.in |
| Who manages | Google (you can't delete reviews) | You (approve/reject in Google Sheet) |
| Can remove bad reviews? | Only if they violate Google policies | Yes — you control everything |
| Helps Google ranking? | Yes — major factor | No |
| Cost | Free | Free |
| How customer leaves review | Via Google link | Via ganeshholidays.in/review.html |

**Best strategy:** Ask every happy customer to review on BOTH platforms.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Can't find "Add business" | Make sure you're at https://business.google.com, signed in with the right Gmail |
| Verification code not received | Wait 24 hours. Try a different method (email instead of phone). Contact Google support. |
| Business not showing in search | Takes 1-4 weeks after verification. Make sure profile is 100% complete. |
| Someone else claimed my business | Click "Request ownership" on the business listing. Google will verify and transfer. |
| Bad review received | Reply professionally. You can flag reviews that violate Google policies. |
| Phone number changed | Edit profile → Contact → update number → Save |
| Want to add WhatsApp | In the description, mention "WhatsApp: +91 7708109824". Google doesn't have a dedicated WhatsApp field, but some apps pick it up. |
